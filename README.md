# Sarıca Mühendislik

Sarıca Mühendislik kurumsal web sitesi — React + Vite.

Canlı: https://saricamuhendislik.com

## Geliştirme

```bash
npm install
npm run dev
```

Yerel adres: http://localhost:5173/

## Yayın

`main` dalına yapılan her push, GitHub Actions ile derlenip doğrudan GitHub Pages'e yayınlanır.
