# Sarıca Mühendislik

Sarıca Mühendislik kurumsal web sitesi — React + Vite.

Canlı: https://scemresahin.github.io/sarica/

## Geliştirme

```bash
npm install
npm run dev
```

Yerel adres: http://localhost:5173/sarica/

## Yayın

`main` dalına yapılan her push, GitHub Actions ile derlenip `gh-pages` dalına atılır ve GitHub Pages'te yayınlanır.
